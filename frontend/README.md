# Frontend starter files

These `pages/` and `components/` files are written for a standard
`create-next-app` (Pages Router, Tailwind) setup. They are NOT a full
Next.js project by themselves — follow Step 3 in the root README to
generate the real project with `npx create-next-app`, then copy these
files in, overwriting the generated `pages/index.js`.

Set your backend URL in a `.env.local` file in this folder once the
real Next.js project exists:

```
NEXT_PUBLIC_API_URL=http://localhost:5000
```
